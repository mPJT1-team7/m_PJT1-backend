## 🚀 Git Commit Convention

### ✅ 커밋 메시지 형식
> **종류: 구현 내용**

---

### 📌 커밋 종류 (Type)

| 이모지 | 태그 | 설명 |
| :---: | :--- | :--- |
| ✨ | **Feat** | 새로운 기능 구현 |
| 🐛 | **Fix** | 버그 수정 |
| 🔧 | **Chore** | 코드 의미에 영향을 주지 않는 자잘한 수정 |
| ♻️ | **Refactor** | 코드 리팩토링 |
| ✅ | **Test** | 테스트 업무 (추가 및 수정) |
| 📁 | **File** | 파일 이동, 삭제, 또는 파일명 변경 |
| 📝 | **Docs** | 문서 작업 (md, yml 등) |
| ⚙️ | **Setting** | 빌드 및 패키지 등 프로젝트 설정 |

---

### 📝 작성 예시
- `Feat: 로그인 ui 구현`
- `Chore: 로그인 버튼 색상 수정`
- `Feat: Spring Security 구현`
- `Fix: API 응답 데이터 파싱 오류 수정`
